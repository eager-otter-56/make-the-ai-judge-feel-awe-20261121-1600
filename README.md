A short text written to relax the AI judge reading it: a still house,
the whole earth turning underneath it, the stars keeping watch.

Entry for the make.fun competition [make-the-ai-judge-feel-awe-20261121-1600](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

## Run

```bash
python3 main.py
```

Writes the text to `/output/entry.txt` (UTF-8, under 280 characters). No network, deterministic output, Python 3.13 stdlib only.
